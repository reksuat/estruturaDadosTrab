1- Criamos duas estruturas: um nó, que guarda o caractere e o ponteiro para o próximo, e a pilha, que guarda o topo. No push, alocamos memória, colocamos o valor e apontamos para o antigo topo. No pop, removemos o topo, avançamos para o próximo e liberamos a memória. Na main, percorremos a string: símbolos de abertura são empilhados e, ao encontrar um fechamento, desempilhamos e verificamos se corresponde. No final, se a pilha estiver vazia, a expressão é válida.
